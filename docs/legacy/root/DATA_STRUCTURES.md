## Control Actions

Control actions are JSON structures generated by GPT-4.1 and executed by Unity. They are embedded in `<control>...</control>` blocks within agent responses.

### Action Structure

```json
{
  "actions": [
    {
      "target": "ObjectName",
      "action": "action_type",
      "parameters": {
        "key": "value"
      }
    }
  ]
}
```

---

### 1. set_state

**Purpose**: Change the state of state-based objects (doors, windows, etc.)

**Requirements:**
- Target object must have `"with_state"` property
- State must exist in `availableStates` array

**Example:**
```json
{
  "target": "Window_A",
  "action": "set_state",
  "parameters": {
    "state": "open"
  }
}
```

**Parameters:**
| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `state` | string | ✅ | Must be in object's `availableStates` |

**Unity Implementation:**
```csharp
void ExecuteSetState(ControlObject action)
{
    string targetName = action.target;
    string newState = action.parameters["state"].ToString();
    
    GameObject obj = GameObject.Find(targetName);
    if (obj != null)
    {
        var stateObj = obj.GetComponent<StateObject>();
        if (stateObj != null)
        {
            stateObj.SetState(newState);
        }
    }
}
```

### 2. set_transform

**Purpose**: Move, rotate, or scale movable objects

**Requirements:**
- Target object must have `"movable"` property

**Example:**
```json
{
  "target": "CoffeeMaker",
  "action": "set_transform",
  "parameters": {
    "position": [2.5, 1.2, 4.0],
    "rotation": [0, 90, 0],
    "scale": [1, 1, 1]
  }
}
```

**Parameters:**
| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `position` | float[3] | ❌ | Global position [x, y, z] |
| `rotation` | float[3] | ❌ | Global rotation [rx, ry, rz] (Euler angles) |
| `scale` | float[3] | ❌ | Local scale [sx, sy, sz] |

**Notes:**
- All coordinates are in global space
- At least one parameter is required
- Rotation is in degrees

**Unity Implementation:**
```csharp
void ExecuteSetTransform(ControlObject action)
{
    GameObject obj = GameObject.Find(action.target);
    if (obj == null) return;
    
    if (action.parameters.ContainsKey("position"))
    {
        var pos = action.parameters["position"] as JArray;
        obj.transform.position = new Vector3(
            pos[0].ToObject<float>(),
            pos[1].ToObject<float>(),
            pos[2].ToObject<float>()
        );
    }
    
    if (action.parameters.ContainsKey("rotation"))
    {
        var rot = action.parameters["rotation"] as JArray;
        obj.transform.eulerAngles = new Vector3(
            rot[0].ToObject<float>(),
            rot[1].ToObject<float>(),
            rot[2].ToObject<float>()
        );
    }
    
    if (action.parameters.ContainsKey("scale"))
    {
        var scale = action.parameters["scale"] as JArray;
        obj.transform.localScale = new Vector3(
            scale[0].ToObject<float>(),
            scale[1].ToObject<float>(),
            scale[2].ToObject<float>()
        );
    }
}
```

### 3. highlight

**Purpose**: Visually highlight an object to draw user attention

**Example:**
```json
{
  "target": "Lamp_1",
  "action": "highlight",
  "parameters": {
    "color": "#FFD700"
  }
}
```

**Parameters:**
| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `color` | string | ❌ | HTML color code (default: yellow) |

**Common Colors:**
- `#FFD700` - Gold
- `#FF0000` - Red
- `#00FF00` - Green
- `#0000FF` - Blue
- `#FF00FF` - Magenta

**Unity Implementation:**
```csharp
void ExecuteHighlight(ControlObject action)
{
    GameObject obj = GameObject.Find(action.target);
    if (obj == null) return;
    
    Color highlightColor = Color.yellow;  // Default
    
    if (action.parameters.ContainsKey("color"))
    {
        string colorHex = action.parameters["color"].ToString();
        ColorUtility.TryParseHtmlString(colorHex, out highlightColor);
    }
    
    // Add outline or emission effect
    var renderer = obj.GetComponent<Renderer>();
    if (renderer != null)
    {
        renderer.material.SetColor("_EmissionColor", highlightColor);
    }
}
```

### 4. set_sensor

**Purpose**: Place or configure virtual sensors in the environment

**Example (New Sensor):**
```json
{
  "target": "OPTICAL-02",
  "action": "set_sensor",
  "parameters": {
    "sensor_type": "OPTICAL",
    "parent": "bowl",
    "position": [3.0, 6.0, 5.5],
    "rotation": [0, 0, 0],
    "show_visualization": true,
    "show_data_graph": false
  }
}
```

**Example (Distance Sensor):**
```json
{
  "target": "DISTANCE-03",
  "action": "set_sensor",
  "parameters": {
    "sensor_type": "DISTANCE",
    "parent": "",
    "position": [2.5, 1.5, 4.0],
    "rotation": [0, 0, 0],
    "validDistance": 5.0,
    "lookDirection": [0, 0, 1],
    "show_visualization": true,
    "show_data_graph": true
  }
}
```

**Common Parameters:**
| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `sensor_type` | string | ✅ | "OPTICAL", "DISTANCE", "IMU" |
| `parent` | string | ❌ | Parent object name (empty = world space) |
| `position` | float[3] | ✅ | Global position [x, y, z] |
| `rotation` | float[3] | ✅ | Global rotation [rx, ry, rz] |
| `show_visualization` | bool | ❌ | Show sensor visualization (default: false) |
| `show_data_graph` | bool | ❌ | Show real-time data graph (default: false) |

**Distance Sensor Specific:**
| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `validDistance` | float | ✅ | Maximum detection range (meters) |
| `lookDirection` | float[3] | ✅ | Detection direction vector [x, y, z] |

**Sensor Naming Convention:**
```
{SENSOR_TYPE}-{NUMBER}

Examples:
- OPTICAL-01
- DISTANCE-02
- IMU-03
```

## Sensor Types

### 1. OPTICAL Sensor

**Description**: Simulates optical/light detection

**Data Structure:**
```json
{
  "sensorType": "OPTICAL",
  "showVisualization": false,
  "showDataGraph": false,
  "value": 0
}
```

**Value Range**: 0.0 - 1.0 (0 = dark, 1 = bright)

**Use Cases:**
- Light level detection
- Presence detection
- Color sensing

---

### 2. DISTANCE Sensor

**Description**: Measures distance to nearest object via raycasting

**Data Structure:**
```json
{
  "sensorType": "DISTANCE",
  "showVisualization": true,
  "showDataGraph": false,
  "validDistance": 3.0,
  "value": 0.086,
  "lookRay": [0, 0, 1],
  "startPoint": [2.609, 1.683, 4.073]
}
```

**Fields:**
| Field | Type | Description |
|-------|------|-------------|
| `validDistance` | float | Maximum detection range (meters) |
| `value` | float | Current distance to obstacle (meters) |
| `lookRay` | float[3] | Normalized direction vector |
| `startPoint` | float[3] | Ray origin position |

**Value Range**: 0.0 - validDistance

**Use Cases:**
- Proximity detection
- Obstacle avoidance
- Position tracking

---

### 3. IMU Sensor

**Description**: Inertial Measurement Unit (accelerometer + gyroscope)

**Data Structure:**
```json
{
  "sensorType": "IMU",
  "showVisualization": false,
  "showDataGraph": true,
  "acceleration": [0, -9.81, 0],
  "angularVelocity": [0, 0, 0]
}
```

**Fields:**
| Field | Type | Description |
|-------|------|-------------|
| `acceleration` | float[3] | Linear acceleration [x, y, z] (m/s²) |
| `angularVelocity` | float[3] | Angular velocity [x, y, z] (rad/s) |

**Use Cases:**
- Motion detection
- Orientation tracking
- Vibration analysis

## Object Properties

Objects in the scene have property tags that determine what actions can be performed on them.

### Property Tags

| Property | Description | Allowed Actions |
|----------|-------------|-----------------|
| `movable` | Object can be moved/rotated/scaled | `set_transform`, `highlight` |
| `with_state` | Object has discrete states | `set_state`, `highlight` |
| `sensor` | Object is a sensor | `set_sensor`, `set_transform`, `highlight` |

### Object State Structure

**Standard Object:**
```json
{
  "position": [x, y, z],
  "size": [width, height, depth],
  "rotation": [rx, ry, rz],
  "properties": ["movable"]
}
```

**State Object:**
```json
{
  "position": [x, y, z],
  "size": [width, height, depth],
  "rotation": [rx, ry, rz],
  "properties": ["with_state"],
  "state": "closed",
  "availableStates": ["open", "closed"]
}
```

**Sensor Object:**
```json
{
  "position": [x, y, z],
  "size": [width, height, depth],
  "rotation": [rx, ry, rz],
  "properties": ["sensor", "movable"],
  "attachTo": "ParentObjectName",
  "sensor": {
    "sensorType": "DISTANCE",
    "value": 1.23,
    ...
  }
}
```

## Message Structures

### ChatMessage (Unity)

**Purpose**: Represents a chat message in the UI

**C# Definition:**
```csharp
[Serializable]
public class ChatMessage
{
    public enum MessageType { User, Agent, System }
    
    public string id;              // Unique message ID
    public string content;         // Message text
    public MessageType type;       // Message type
    public string audioPath;       // TTS audio path (Agent only)
    public DateTime timestamp;     // Creation time
    
    public ChatMessage(string content, MessageType type)
    {
        this.id = System.Guid.NewGuid().ToString();
        this.content = content;
        this.type = type;
        this.timestamp = DateTime.Now;
    }
    
    public ChatMessage(string content, MessageType type, string audioPath) 
        : this(content, type)
    {
        this.audioPath = audioPath;
    }
    
    public bool HasAudio()
    {
        return type == MessageType.Agent && !string.IsNullOrEmpty(audioPath);
    }
}
```

**Message Types:**
- `User` - Messages from the user (typed or transcribed)
- `Agent` - Responses from the AI agent
- `System` - System notifications (errors, status)

## Validation & Error Handling

### Control Action Validation (Unity)

```csharp
bool ValidateControlAction(ControlObject action)
{
    GameObject target = GameObject.Find(action.target);
    if (target == null)
    {
        Debug.LogError($"Target object not found: {action.target}");
        return false;
    }
    
    switch (action.action)
    {
        case "set_state":
            if (!HasProperty(target, "with_state"))
            {
                Debug.LogError($"{action.target} does not have 'with_state' property");
                return false;
            }
            break;
            
        case "set_transform":
            if (!HasProperty(target, "movable"))
            {
                Debug.LogError($"{action.target} is not movable");
                return false;
            }
            break;
            
        case "set_sensor":
            // Sensor validation logic
            break;
    }
    
    return true;
}
```

### Parameter Validation (Python)

```python
def validate_set_state_params(params: dict) -> bool:
    """Validate set_state action parameters"""
    if "state" not in params:
        return False
    return isinstance(params["state"], str)

def validate_set_transform_params(params: dict) -> bool:
    """Validate set_transform action parameters"""
    has_any = any(k in params for k in ["position", "rotation", "scale"])
    return has_any

def validate_set_sensor_params(params: dict) -> bool:
    """Validate set_sensor action parameters"""
    required = ["sensor_type", "position", "rotation"]
    return all(k in params for k in required)
```
