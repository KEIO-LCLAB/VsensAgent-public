### 5. **ControlManager.cs 过于庞大**
**严重度**: 🟡 Medium

**统计**:
- 文件大小: **647行**
- 方法数量: 20+
- 职责: 处理所有类型的场景物体控制

**问题**:
- 单个类过大，难以维护
- 包含多种不同类型的控制逻辑
- 缺少策略模式或命令模式

**建议重构**:
```
ControlManager/ (文件夹)
├── ControlManager.cs           (核心调度器, ~150行)
├── Handlers/
│   ├── SensorControlHandler.cs
│   ├── StateObjectHandler.cs
│   ├── AnimationControlHandler.cs
│   └── IControlHandler.cs     (接口)
└── Commands/
    ├── SetSensorCommand.cs
    ├── SetStateCommand.cs
    └── ICommand.cs             (接口)
```

使用策略模式:
```csharp
public interface IControlHandler
{
    bool CanHandle(string action);
    void Handle(GameObject target, WsClient.ControlObject ctrl);
}

public class ControlManager : MonoBehaviour
{
    private List<IControlHandler> handlers;
    
    void Start()
    {
        handlers = new List<IControlHandler>
        {
            new SensorControlHandler(),
            new StateObjectHandler(),
            new AnimationControlHandler()
        };
    }
    
    private void HandleSingleControl(WsClient.ControlObject ctrl)
    {
        var handler = handlers.FirstOrDefault(h => h.CanHandle(ctrl.action));
        handler?.Handle(targetObj, ctrl);
    }
}
```

### 6. **缺少依赖注入/服务定位器**
**严重度**: 🟡 Medium

**问题示例**:
```csharp
// ChatUIManager.cs
audioRecorder = FindFirstObjectByType<AudioRecorder>();

// InputManager.cs  
audioRecorder = Object.FindFirstObjectByType<AudioRecorder>();

// SensorMonitorManager.cs
sensorManager = VsensAgentSensorManager.Instance;
```

**问题**:
- 大量使用 `FindObjectOfType` (性能开销)
- 硬编码的单例模式
- 缺少解耦

**建议方案**:
创建简单的服务定位器:
```csharp
// ServiceLocator.cs
namespace VsensAgent.Core
{
    public static class ServiceLocator
    {
        private static Dictionary<Type, object> services = new();
        
        public static void Register<T>(T service)
        {
            services[typeof(T)] = service;
        }
        
        public static T Get<T>() where T : class
        {
            return services.TryGetValue(typeof(T), out var service) 
                ? service as T 
                : null;
        }
    }
}

// 使用示例:
void Start()
{
    ServiceLocator.Register(this); // 注册自己
    
    // 获取服务
    audioRecorder = ServiceLocator.Get<AudioRecorder>();
}
```
